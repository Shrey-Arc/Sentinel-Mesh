Cross-functional touchpoints — where the team works together
Physical build sessions (P1 + P2)
Assembly days: P1 holds structure, P2 routes and solders wiring. Neither can finish without the other present. Plan 2–3 dedicated build days per milestone.
First hover (P1 + P2 + P3)
P1 delivers the frame. P2 delivers the powered electronics. P3 delivers the calibrated PX4. This is the first hard convergence point. Tethered indoor, safety observer mandatory.
FC ↔ Jetson integration (P3 + P4)
MAVLink serial bridge, ROS2 topic design, SOC energy-aware trigger. P3 owns the FC side, P4 owns the Jetson side. Design the message interface jointly before coding it separately.
SLAM → EKF aiding (P3 + P4)
P4 runs FAST-LIO2 and publishes odometry. P3 consumes it in EKF3 as external vision. Both must agree on the TF frame tree and covariance values before integration.
AI benchmark campaign (P3 + P4)
P3 runs SITL environment. P4 runs AI models inside it. 50 simulated + 15 real trials per model. Data logging software built by P4, hardware piloting by P3.
Docking station integration (P1 + P2 + P4)
P1 delivers physical docking station. P2 delivers charging electronics. P4 delivers approach controller and AprilTag vision. All three must be present for docking trials.
Fleet rotation demo (all four)
2+ physical drones (P1 built them), power architecture in both (P2), PX4 tuned on both (P3), mesh + scheduler running (P4). The only task requiring all four simultaneously. Target: two drones, one dock, one full rotation cycle.
Characterization data → research docs (P2 + everyone)
P2 generates the acoustic, vibration, endurance, and power datasets that directly feed Tables I–IV in the journal paper. Everyone validates against their own subsystem predictions.
